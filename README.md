Student Performance Analysis

Project Overview
This project focuses on analyzing student academic performance using data analysis techniques. The goal is to understand how various demographic, social, and behavioral factors influence student scores in 'Math, Reading, and Writing'.

Objectives
- Analyze the impact of different factors on student performance
- Identify trends and patterns in academic scores
- Compare performance across different student groups
- Generate insights using data visualization

Dataset Description
The dataset contains student-level data with the following features:

- Gender  
- Ethnic Group  
- Parent Education  
- Lunch Type  
- Test Preparation  
- Parent Marital Status  
- Practice Sport  
- First Child  
- Number of Siblings  
- Transport Means  
- Weekly Study Hours  
- Math Score  
- Reading Score  
- Writing Score  

Tools & Technologies Used
- Python
- Pandas – Data cleaning & manipulation  
- NumPy – Numerical operations  
- Matplotlib & Seaborn – Data visualization  

 Data Preprocessing
- Imported dataset using Pandas  
- Handled missing values  
- Removed null records  
- Created a new feature: 'Average Score

Exploratory Data Analysis (EDA)
- Distribution analysis using histograms & boxplots  
- Group comparisons using bar charts  
- Trend analysis across multiple categories  

Key Analysis

Gender
- Female students performed slightly better overall

Ethnic Group
- Performance varies across groups  
- Ethnic Group E showed the highest scores  

Parent Education
- Higher parental education → better student performance  

Test Preparation
- Students who completed test prep scored higher  

Weekly Study Hours
- More study time → higher scores  

Sports Activity
- Regular sports participation supports balanced performance  

Parent Marital Status
- Minimal impact on student performance  

 Key Insights
- Test preparation significantly improves scores  
- Study hours have a strong positive impact  
- Parental education plays a crucial role  
- Female students perform slightly better overall  
- Sports help maintain consistent performance  

Conclusion
Student performance is influenced by multiple factors such as 'study habits, parental background, and preparation strategies'. This analysis highlights the importance of structured learning and consistent study patterns.
